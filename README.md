# IconBrowser

مرورگر ساده‌ی اندرویدی (WebView) با قابلیت تغییر آیکون و نام برنامه (مرورگر، هواشناسی، رادیو، تلفن، ماشین‌حساب، یادداشت، ساعت، تقویم) از داخل تنظیمات.

## نکات
- **تعویض آیکون:** با `activity-alias`ها در `AndroidManifest.xml` و `IconSwitcher.kt`.
- **پاک‌سازی خودکار تاریخچه:** در تنظیمات (بخش حریم خصوصی)؛ بی‌صدا با باز و بسته شدن برنامه. کوکی‌ها به‌صورت پیش‌فرض نگه داشته می‌شوند تا صفحه‌ی تأیید Cloudflare/گوگل هر بار ظاهر نشود؛ کلید «پاک کردن کوکی‌ها هم» جداست.
- **نصب روی نسخه‌ی قبلی:** امضا باید همیشه یکسان باشد. فایل `keystore/debug.keystore` را فقط یک‌بار بساز/نگه دار و در ریپازیتوری commit کن (همان که قبلاً push کردی را عوض نکن). اگر این فایل نباشد، ورک‌فلو یک کلید موقت می‌سازد که روی نصب قبلی آپدیت نمی‌شود.

## ساخت APK
فایل‌ها را در گیت‌هاب push کن؛ در تب Actions ورک‌فلو «Build APK» اجرا می‌شود و `app-debug-apk` در بخش Artifacts قرار می‌گیرد.
